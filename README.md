# Sổ Lớp

App web (PWA) mở hệ thống Sổ Lớp toàn màn hình, cài được lên điện thoại.

- `index.html` – trang app; dòng `APP_URL` là đường dẫn web app Apps Script (/exec).
- `manifest.webmanifest`, `sw.js`, các ảnh `icon-*.png` – tên, biểu tượng và chế độ cài đặt.

Dữ liệu nằm trong Google Sheet của chủ hệ thống; repository này không chứa dữ liệu người dùng.
